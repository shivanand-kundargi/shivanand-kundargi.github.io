Author Authentication

To edit and publish notes directly to your GitHub repository (shivanand-kundargi.github.io), enter your GitHub Personal Access Token.

How to get a token in 30 seconds:
  1. Go to GitHub Fine-Grained Personal Access Tokens.
  2. Click Generate new token.
  3. Repository Access: select Only select repositories → shivanand-kundargi.github.io.
  4. Permissions: select Repository permissions → Contents → Read and write.
  5. Generate and paste the token below.
🔒 Your token is saved only in your local browser's storage and is sent directly to api.github.com over HTTPS.
